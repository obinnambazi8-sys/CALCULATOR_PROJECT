Project Overview

This is a command-line calculator developed using Python. It performs basic arithmetic operations, including addition, subtraction, multiplication, and division.

The calculator allows users to enter two numbers, select an arithmetic operation, and view the result. It also provides an option to continue calculating using the previous result or start a new calculation.

The project uses Python functions and a dictionary to associate arithmetic operators with their corresponding operations. It also uses the os module to clear the terminal screen when starting a new calculation.

This project was developed to practise Python functions, dictionaries, loops, conditional statements, user input handling, and basic arithmetic operations.

Features

Addition (+): Adds two numbers.

Subtraction (-): Subtracts one number from another.

Multiplication (*): Multiplies two numbers.

Division (/): Divides one number by another.

Continuous Calculations: Allows users to continue calculating using the previous result.

Function Mapping: Uses a dictionary to associate arithmetic operators with their respective functions.

Screen Clearing: Uses Python's os module to clear the terminal when starting a new calculation.

Interactive Interface: Provides a command-line interface for performing calculations.
How It Works

The calculator follows these steps:

Prompts the user to enter the first number.

Displays the available arithmetic operators.

Asks the user to select an operation.

Requests the second number.

Executes the selected arithmetic function.

Displays the calculation and its result.

Asks whether the user wants to continue calculating with the previous result.

If the user chooses to continue, the previous result becomes the first number in the next calculation.

If the user chooses to stop, the terminal screen is cleared and the calculator exits.
